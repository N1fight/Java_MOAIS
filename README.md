# Лабораторная работа № 1. Банковский счёт

## Описание работы

Реализовано консольное приложение «Банк» для работы с несколькими банковскими счетами. Пользователь может просмотреть список счетов, выбрать счёт, получить сведения о нём, пополнить баланс, снять средства и узнать количество созданных счетов.

Программа состоит из двух классов в пакете `lab1`.

| Файл | Назначение |
|---|---|
| `BankAccount.java` | Хранение данных счёта, проверка сумм и выполнение банковских операций |
| `Main.java` | Создание счетов, вывод меню и обработка пользовательского ввода |

## Теоретические основы

### Классы, объекты и поля

Класс описывает данные и действия объектов. Каждый объект `BankAccount` представляет отдельный банковский счёт.

```java
new BankAccount("Константин Тулинов", "1001", 1500.00)
```

У каждого счёта есть собственные поля `owner`, `accountNumber` и `balance`. Изменение баланса одного объекта не изменяет баланс остальных.

Тип `double` является примитивным и используется для хранения баланса. Типы `String` и `BankAccount` являются ссылочными. Переменная `selected` хранит ссылку на выбранный объект.

### Инкапсуляция

Поля класса `BankAccount` объявлены с модификатором `private`. Доступ к данным предоставляют методы `getOwner()`, `getAccountNumber()` и `getBalance()`.

Изменение баланса выполняется через `deposit()` и `withdraw()`. Это позволяет проверить корректность операции до изменения состояния счёта.

Поля `owner` и `accountNumber` дополнительно объявлены как `final`, поэтому присвоить им другое значение после инициализации нельзя.

### Конструкторы и перегрузка

Конструктор вызывается при создании объекта и задаёт его начальное состояние. В классе реализованы два конструктора.

```java
BankAccount(String owner, String accountNumber)
BankAccount(String owner, String accountNumber, double initialBalance)
```

Первый создаёт счёт с нулевым балансом и вызывает второй через `this(owner, accountNumber, 0.0)`. Это пример перегрузки конструкторов и повторного использования кода.

Основной конструктор проверяет имя владельца, номер счёта и начальный баланс. При недопустимых значениях выбрасывается `IllegalArgumentException`.

### Статические поля и методы

Поле `static int accountsCount` принадлежит всему классу. Оно увеличивается при успешном создании каждого счёта.

Метод `getAccountsCount()` вызывается через имя класса.

```java
BankAccount.getAccountsCount()
```

Оба конструктора используют общую инициализацию, поэтому каждый созданный объект учитывается один раз.

### Массив объектов

Счета хранятся в массиве `BankAccount[]`. Каждый элемент массива содержит ссылку на объект счёта.

Индексы массива начинаются с нуля, а пункты списка для пользователя — с единицы. Поэтому выбор выполняется так.

```java
selected = accounts[number - 1];
```

При этом новый объект не создаётся. Переменная `selected` начинает ссылаться на существующий счёт из массива.

### Условия, циклы и выбор действий

Цикл `while` повторяет главное меню, пока переменная `running` равна `true`. Конструкция `switch` выбирает действие по введённой команде.

Условия `if` проверяют выбор счёта, корректность индекса и допустимость суммы. Цикл `for` используется для вывода списка счетов.

Команда `"0"` присваивает `running` значение `false`, после чего цикл завершается.

### Пользовательский ввод и обработка ошибок

Ввод выполняется через `Scanner`. Метод `nextLine()` получает строку, а `Integer.parseInt()` и `Double.parseDouble()` преобразуют её в число.

Перед преобразованием суммы запятая заменяется точкой, поэтому допустимы оба варианта ввода — `100.50` и `100,50`.

Если строку нельзя преобразовать в число, возникает `NumberFormatException`. Блок `catch` перехватывает исключение и выводит сообщение.

Методы банковских операций возвращают `boolean`. Значение `true` означает успешное выполнение операции, `false` — отказ после проверки данных.

# Лабораторная работа № 2. Классы, наследование и преобразование типов

## Описание работы

Реализовано консольное приложение «Автопарк», демонстрирующее наследование, полиморфизм и преобразование ссылочных типов.

В программе создаются автомобиль, мотоцикл, грузовик и электробус. Все объекты сохраняются в массиве `Vehicle[]`. При обходе массива выводятся характеристики транспорта, вызывается метод движения и выполняются действия, доступные конкретным классам.

Программа автоматически выполняет демонстрацию и завершает работу.

| Файл              | Назначение                                                   |
|-------------------|--------------------------------------------------------------|
| `Vehicle.java`    | Абстрактный класс транспорта и вложенный класс двигателя      |
| `Car.java`        | Класс автомобиля с количеством пассажиров и открытием багажника |
| `Motorcycle.java` | Класс мотоцикла с признаком наличия коляски                    |
| `Truck.java`      | Класс грузовика с грузоподъёмностью и проверкой массы груза    |
| `Main.java`       | Создание объектов, обход массива и преобразование типов       |

Все файлы находятся в папке `src/lab2` и относятся к пакету `lab2`.

## Теоретические основы

### Абстрактный класс

Абстрактный класс описывает общие характеристики и поведение группы объектов. В работе таким классом является `Vehicle`.

```java
public abstract class Vehicle {
    // Общие поля и методы транспорта.
}
```

В нём находятся поля `brand`, `model`, `year` и `engine`, а также метод `printInfo()` для вывода информации.

Абстрактный метод объявляется без тела.

```java
public abstract void move();
```

Конкретные классы-наследники обязаны реализовать этот метод. Создать объект непосредственно абстрактного класса нельзя.

### Наследование

Наследование позволяет создавать классы на основе существующего класса. В работе `Car`, `Motorcycle` и `Truck` наследуют `Vehicle`.

```java
public class Car extends Vehicle {
    // Собственные поля и методы автомобиля.
}
```

Общая часть объекта инициализируется через вызов конструктора родителя.

```java
super(brand, model, year, engine);
```

После этого конструктор наследника инициализирует собственные поля. Например, `Car` сохраняет количество пассажиров в `passengerCount`.

### Инкапсуляция

Поля классов объявлены с модификатором `private`. Это ограничивает прямой доступ к состоянию объектов.

Класс `Main` взаимодействует с транспортом через методы `printInfo()`, `move()`, `openTrunk()`, `doWheelie()` и `loadCargo()`.

Поля, значения которых задаются при создании и больше не меняются, объявлены как `final`.

### Переопределение методов

Переопределение позволяет наследнику задать собственную реализацию метода родительского класса.

```java
@Override
public void move() {
    System.out.println("Автомобиль едет по дороге.");
}
```

Аннотация `@Override` позволяет компилятору проверить, что метод действительно переопределяет метод родителя.

В каждом классе транспорта реализован свой вариант `move()`.

### Восходящее преобразование типов

Восходящее преобразование происходит при присваивании ссылки на объект наследника переменной родительского типа.

```java
Vehicle car = new Car(
        "Lada", "Vesta", 2022,
        new Vehicle.Engine(106, "бензиновый"), 3);
```

Тип переменной `car` — `Vehicle`, а фактический класс объекта — `Car`. Такое преобразование выполняется автоматически.

Благодаря общему родительскому типу разные транспортные средства можно хранить в одном массиве.

```java
Vehicle[] vehicles = {car, motorcycle, truck, electricBus};
```

### Полиморфизм

Полиморфизм позволяет вызывать общий метод через ссылку родительского типа и получать поведение конкретного объекта.

```java
for (Vehicle vehicle : vehicles) {
    vehicle.move();
}
```

Для автомобиля выполняется `Car.move()`, для мотоцикла — `Motorcycle.move()`, для грузовика — `Truck.move()`. Для электробуса выполняется реализация из анонимного класса.

Выбор реализации происходит во время выполнения программы по фактическому классу объекта.

### Нисходящее преобразование типов

Через переменную типа `Vehicle` доступны методы, объявленные в `Vehicle`. Для вызова специального метода наследника используется нисходящее преобразование.

```java
if (vehicle instanceof Car) {
    Car currentCar = (Car) vehicle;
    currentCar.openTrunk();
}
```

Оператор `instanceof` проверяет, можно ли рассматривать объект как `Car`. После успешной проверки выполняется явное приведение `(Car) vehicle`.

При приведении новый объект не создаётся. Переменные `vehicle` и `currentCar` ссылаются на один автомобиль.

### Ошибка ClassCastException

Если ссылка указывает на мотоцикл, привести её к автомобилю нельзя.

```java
// Car wrongCar = (Car) motorcycle;
```

Переменная `motorcycle` объявлена как `Vehicle`, поэтому такое выражение допускается компилятором. Однако при выполнении возникнет `ClassCastException`, поскольку фактический объект имеет класс `Motorcycle`.

В программе ошибочный пример оставлен в комментарии. Выполняемые преобразования защищены проверками `instanceof`.

### Вложенный класс Engine

Класс `Engine` объявлен внутри `Vehicle`.

```java
public static class Engine {
    private final int power;
    private final String type;
}
```

Он хранит мощность и тип двигателя. Метод `printEngineInfo()` выводит эти характеристики.

Модификатор `static` позволяет создавать двигатель без предварительного создания объекта `Vehicle`.

```java
new Vehicle.Engine(106, "бензиновый")
```

Каждое транспортное средство получает объект двигателя через конструктор и хранит ссылку на него в поле `engine`.

### Ключевое слово final

Модификатор `final` у поля запрещает повторное присваивание после инициализации. Например, поле `engine` продолжает ссылаться на тот же двигатель.

В работе также используется метод `final`.

```java
public final void printInfo() {
    // Вывод общих характеристик.
}
```

Наследники могут вызывать этот метод, но не могут переопределить его. Таким образом сохраняется общая процедура вывода характеристик транспорта.

### Анонимный класс

Анонимный класс позволяет создать подкласс без отдельного имени и файла.

```java
Vehicle electricBus = new Vehicle(
        "КамАЗ", "6282", 2021,
        new Vehicle.Engine(250, "электрический")) {

    @Override
    public void move() {
        System.out.println("Электробус следует по городскому маршруту.");
    }
};
```

Здесь создаётся объект анонимного наследника `Vehicle`, который реализует абстрактный метод `move()`.

Электробус включён в общий массив, поэтому его метод движения вызывается в том же цикле, что и методы остальных объектов.

## Проверки входных данных

В конструкторах и методе загрузки предусмотрены проверки.

| Проверка                                | Поведение программы                                        |
|-----------------------------------------|------------------------------------------------------------|
| Двигатель равен `null`                   | Конструктор `Vehicle` выбрасывает `IllegalArgumentException` |
| Мощность двигателя не положительна       | Конструктор `Engine` выбрасывает `IllegalArgumentException` |
| Тип двигателя отсутствует или пуст      | Конструктор `Engine` выбрасывает `IllegalArgumentException` |
| Количество пассажиров отрицательно      | Конструктор `Car` выбрасывает `IllegalArgumentException`    |
| Грузоподъёмность неконечна или не положительна | Конструктор `Truck` выбрасывает `IllegalArgumentException` |
| Масса груза неконечна или не положительна | `loadCargo()` выводит сообщение об ошибке                   |
| Масса груза превышает грузоподъёмность   | `loadCargo()` отклоняет загрузку и выводит сообщение         |

В демонстрации используются корректные аргументы конструкторов. Метод `loadCargo()` проверяет массу одной загрузки; накопленная масса груза в объекте не хранится.

# Лабораторная работа № 3. Универсальное хранилище объектов

## Описание работы

Реализовано консольное приложение «Универсальное хранилище». Обобщённый класс `Storage<T>` хранит элементы выбранного типа в обычном массиве.

Хранилище поддерживает добавление, получение, замену и удаление элементов. Также можно узнать количество элементов, вместимость массива и проверить, пусто ли хранилище.

В программе один класс используется для строк `String` и целых чисел `Integer`. Демонстрация выполняется автоматически при запуске.

| Файл           | Назначение                                             |
|----------------|--------------------------------------------------------|
| `Storage.java` | Хранение элементов, операции с массивом и проверки      |
| `Main.java`    | Демонстрация операций и обработка ожидаемых исключений  |

Оба файла находятся в папке `src/lab3` и относятся к пакету `lab3`.

## Теоретические основы

### Обобщённый класс

Обобщения позволяют использовать один класс с различными типами данных. В объявлении `Storage<T>` буква `T` обозначает тип сохраняемых элементов.

```java
public class Storage<T> {
    private final T[] elements;
    private int size;
}
```

При создании объекта вместо `T` указывается конкретный тип.

```java
Storage<String> names = new Storage<>(new String[3]);
Storage<Integer> numbers = new Storage<>(new Integer[2]);
```

Для `names` методы принимают и возвращают строки, для `numbers` — целые числа типа `Integer`.

Компилятор проверяет соответствие типов. Например, попытка добавить строку в `Storage<Integer>` приведёт к ошибке компиляции.

### Класс Integer и автоупаковка

Параметрами обобщённых типов могут быть ссылочные типы. Поэтому для целых чисел используется класс `Integer`.

```java
numbers.add(10);
```

При этом Java автоматически преобразует значение примитивного типа `int` в объект `Integer`. Это называется автоупаковкой.

### Массив и параметр типа

Внутри класса массив объявлен как `T[]`. Создать его выражением `new T[3]` нельзя, поэтому конкретный массив передаётся в конструктор.

```java
public Storage(T[] buffer) {
    if (buffer == null || buffer.length == 0) {
        throw new IllegalArgumentException(
                "Необходимо передать массив положительной длины.");
    }

    elements = buffer;
    size = 0;
}
```

По условию вызывающий код передаёт заранее созданный пустой массив. Например, все ячейки `new String[3]` первоначально содержат `null`.

Конструктор сохраняет ссылку на переданный массив. В демонстрации массив создаётся непосредственно при вызове конструктора, а дальнейшая работа выполняется через методы хранилища.

### Инкапсуляция

Поля `elements` и `size` объявлены с модификатором `private`. Код класса `Main` обращается к хранилищу через его методы.

Поле `elements` также объявлено как `final`. Это запрещает присвоить полю ссылку на другой массив, но позволяет изменять элементы существующего массива.

### Размер и вместимость

Вместимость определяется длиной массива и остаётся постоянной. Размер `size` показывает количество сохранённых элементов и изменяется после добавления или удаления.

Например, при вместимости 3 и размере 2 заняты ячейки с индексами 0 и 1. Ячейка с индексом 2 свободна.

```java
public int size() {
    return size;
}

public int capacity() {
    return elements.length;
}

public boolean isEmpty() {
    return size == 0;
}
```

Допустимый индекс существующего элемента удовлетворяет условию `0 <= index < size`.

### Добавление элемента

Метод `add()` проверяет значение и наличие свободного места, затем записывает элемент в ячейку с индексом `size`.

```java
elements[size] = value;
size++;
```

Если до добавления `size` равен 2, новый элемент записывается в ячейку 2, после чего размер становится равен 3.

При заполненном массиве выбрасывается `IllegalStateException`.

### Получение и замена

Метод `get()` возвращает элемент по индексу. Метод `set()` заменяет значение существующего элемента.

```java
String name = names.get(1);
names.set(1, "Мария");
```

Оба метода проверяют индекс. Метод `set()` дополнительно запрещает значение `null`.

Получение и замена не изменяют размер хранилища.

### Удаление со сдвигом

Метод `remove()` возвращает удалённый элемент и сохраняет непрерывность занятой части массива.

Для массива `[Анна, Мария, Ольга]` вызов `remove(1)` выполняет следующие действия.

1. Проверяет индекс 1.
2. Сохраняет значение `"Мария"` в переменной `removed`.
3. Перемещает `"Ольга"` из ячейки 2 в ячейку 1.
4. Уменьшает `size` с 3 до 2.
5. Записывает `null` в освободившуюся ячейку 2.
6. Возвращает `"Мария"`.

```java
for (int i = index; i < size - 1; i++) {
    elements[i] = elements[i + 1];
}

size--;
elements[size] = null;
```

После удаления массив содержит `[Анна, Ольга, null]`, а размер хранилища равен 2.

При удалении последнего элемента сдвиг не требуется, поэтому тело цикла не выполняется.

### Исключения и проверка аргументов

Исключения сообщают вызывающему коду о недопустимой операции.

| Исключение                  | Когда возникает                                           |
|-----------------------------|-----------------------------------------------------------|
| `IllegalArgumentException`  | В конструктор передан `null` или массив нулевой длины       |
| `IllegalArgumentException`  | В `add()` или `set()` передано значение `null`              |
| `IllegalStateException`     | Выполняется добавление в заполненное хранилище             |
| `IndexOutOfBoundsException` | Индекс меньше нуля или не меньше текущего размера          |

Проверки выполняются до изменения данных. При отклонении операции содержимое и размер хранилища сохраняются.

В `Main` ожидаемые исключения перехватываются через `try/catch`.

```java
try {
    names.add("Павел");
} catch (IllegalStateException error) {
    System.out.println("Проверка переполнения: " + error.getMessage());
}
```

После вывода сообщения программа продолжает демонстрацию.

### Символ ? в параметре метода

Метод вывода состояния принимает `Storage<?>`.

```java
private static void printState(Storage<?> storage) {
    // Вывод размера, вместимости и элементов.
}
```

Символ `?` обозначает неизвестный тип элементов. Благодаря этому один метод может выводить и `Storage<String>`, и `Storage<Integer>`.

Для просмотра размера и вывода элементов знание конкретного типа не требуется.

### Сложность операций

Получение, замена и добавление элемента выполняются за `O(1)` — количество действий не зависит от числа сохранённых элементов.

Удаление в худшем случае занимает `O(n)`, поскольку требует сдвига всех следующих элементов. Удаление последнего элемента занимает `O(1)`.

# Лабораторная работа № 4. Универсальный калькулятор

## Описание работы

Реализовано консольное приложение «Универсальный калькулятор». Обобщённый класс `Calculator<T extends Number>` хранит два числа выбранного типа и выполняет арифметические операции.

Калькулятор поддерживает сложение, вычитание, умножение, деление и вычисление среднего арифметического. Дополнительно реализован статический обобщённый метод для возведения числа в квадрат.

В программе один класс используется с типами `Integer` и `Double`. Демонстрация выполняется автоматически при запуске.

| Файл              | Назначение                                            |
|-------------------|-------------------------------------------------------|
| `Calculator.java` | Хранение чисел, арифметические операции и проверки      |
| `Main.java`       | Демонстрация вычислений и обработка ожидаемых ошибок    |

Оба файла находятся в папке `src/lab4` и относятся к пакету `lab4`.

Номер работы соответствует названию исходного файла. Внутри PDF на титульной странице указана лабораторная работа № 5.

## Теоретические основы

### Обобщённый класс с ограничением типа

Обобщения позволяют использовать одну реализацию класса для разных типов данных.

```java
public class Calculator<T extends Number> {
    private final T first;
    private final T second;
}
```

Параметр `T` обозначает тип операндов. Ограничение `extends Number` означает, что вместо `T` можно использовать `Number` или его подклассы, например `Integer` и `Double`.

Благодаря этому ограничению внутри класса доступен метод `doubleValue()`, объявленный в `Number`.

```java
Calculator<Integer> integers = new Calculator<>(5, 2);
Calculator<Double> decimals = new Calculator<>(-4.5, 1.5);
```

У первого объекта оба операнда имеют тип `Integer`, у второго — `Double`. Использовать `Calculator<String>` нельзя, поскольку `String` не наследует `Number`.

### Инкапсуляция и конструктор

Поля `first` и `second` объявлены как `private`, поэтому прямой доступ к ним из `Main` запрещён.

Модификатор `final` запрещает присвоить полям другие значения после инициализации.

Конструктор проверяет аргументы перед сохранением.

```java
public Calculator(T first, T second) {
    if (first == null || second == null) {
        throw new IllegalArgumentException("Оба числа должны быть заданы.");
    }

    this.first = first;
    this.second = second;
}
```

Если хотя бы один аргумент равен `null`, создание объекта завершается исключением `IllegalArgumentException`.

### Классы Integer и Double

Обобщённые типы работают со ссылочными типами. Поэтому вместо примитивных типов `int` и `double` используются классы-обёртки `Integer` и `Double`.

При создании калькулятора Java автоматически упаковывает переданные примитивные значения в соответствующие объекты.

```java
Calculator<Integer> integers = new Calculator<>(5, 2);
```

Числа `5` и `2` автоматически преобразуются из `int` в `Integer`.

### Преобразование через doubleValue()

К значениям типа `T` нельзя непосредственно применять арифметические операторы.

Перед вычислением каждый операнд преобразуется в `double`.

```java
public double add() {
    return first.doubleValue() + second.doubleValue();
}
```

Это позволяет использовать одинаковую реализацию для разных подклассов `Number`. Приведение к конкретным классам `Integer` или `Double` внутри калькулятора не требуется.

Все арифметические методы возвращают результат типа `double`.

### Арифметические операции

Пусть `a` и `b` — значения операндов после преобразования в `double`.

| Метод        | Вычисление | Назначение                        |
|--------------|------------|-----------------------------------|
| `add()`      | `a + b`    | Сложение                          |
| `subtract()` | `a - b`    | Вычитание второго числа из первого |
| `multiply()` | `a * b`    | Умножение                         |
| `divide()`   | `a / b`    | Деление первого числа на второе   |
| `average()`  | `(a + b) / 2` | Среднее арифметическое         |

Метод `average()` повторно использует уже реализованный метод сложения.

```java
public double average() {
    return add() / 2.0;
}
```

### Дробное деление

При делении двух значений типа `int` дробная часть результата отбрасывается. Например, выражение `5 / 2` даёт `2`.

В калькуляторе операнды преобразуются в `double` до деления, поэтому для чисел `5` и `2` результат равен `2.5`.

```java
return first.doubleValue() / divisor;
```

### Проверка нулевого делителя

Вычисления с `double` при делении на ноль могут возвращать бесконечность или `NaN`. По условию работы калькулятор должен выбрасывать исключение.

Поэтому делитель проверяется явно.

```java
double divisor = second.doubleValue();

if (divisor == 0.0) {
    throw new ArithmeticException("Деление на ноль.");
}
```

Проверка также отклоняет значение `-0.0`, поскольку при сравнении оно равно `0.0`.

### Обработка исключений

В `Main` ожидаемые ошибки перехватываются через `try/catch`.

```java
try {
    Calculator<Integer> zeroDivisor = new Calculator<>(5, 0);
    zeroDivisor.divide();
} catch (ArithmeticException error) {
    System.out.println("Проверка деления: " + error.getMessage());
}
```

Создание калькулятора с нулевым вторым операндом разрешено. Исключение возникает при вызове `divide()`, поскольку остальные операции с нулём допустимы.

Отдельный блок проверяет передачу `null` в конструктор. После обработки исключений программа продолжает выполнение.

### Статический обобщённый метод

Дополнительный метод `square()` вычисляет квадрат переданного числа.

```java
public static <N extends Number> double square(N value) {
    if (value == null) {
        throw new IllegalArgumentException("Число должно быть задано.");
    }

    double number = value.doubleValue();
    return number * number;
}
```

Метод объявлен как `static`, поэтому вызывается через имя класса и не требует создания объекта.

```java
Calculator.square(5);
Calculator.square(-1.5);
```

Параметр `N` принадлежит самому методу. Он объявлен отдельно от параметра `T` класса, поскольку статический метод не связан с конкретным экземпляром калькулятора.

Компилятор определяет тип `N` по переданному аргументу.

### Символ ? в параметре метода

Метод вывода результатов принимает `Calculator<?>`.

```java
private static void printResults(Calculator<?> calculator) {
    // Вызов арифметических методов и вывод результатов.
}
```

Символ `?` обозначает неизвестный допустимый тип операндов. Один метод вывода подходит и для `Calculator<Integer>`, и для `Calculator<Double>`.

Конкретный тип операндов для вывода не требуется, поскольку все арифметические методы возвращают `double`.

### Особенности вычислений с double

Тип `double` имеет ограниченную точность. Некоторые десятичные дроби представляются приближённо, поэтому результаты вычислений могут округляться.

При очень больших значениях возможно переполнение. В частности, промежуточная сумма в `average()` может стать бесконечной. В работе используется обычная формула среднего арифметического, соответствующая учебному заданию.
